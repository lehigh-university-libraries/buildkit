# Hypercube

Docker image for [Hypercube]. Tesseract as a microservice

Built from [lehigh-university-libraries/buildkit hypercube](https://github.com/lehigh-university-libraries/buildkit/tree/main/images/hypercube)

## Dependencies

Requires `lehighlts/scyllaridae` Docker image to build. Please refer to the
[Scyllaridae Image README](../scyllaridae/README.md) for additional information including
additional settings, volumes, ports, etc.
