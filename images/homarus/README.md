# Homarus

Docker image for [Homarus]. FFmpeg as a microservice.

Built from [lehigh-university-libraries/buildkit homarus](https://github.com/lehigh-university-libraries/buildkit/tree/main/images/homarus)


## Dependencies

Requires `lehighlts/scyllaridae` Docker image to build. Please refer to the
[Scyllaridae Image README](../scyllaridae/README.md) for additional information including
additional settings, volumes, ports, etc.
